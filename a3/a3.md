ii. 
+ Advantage: Better Performance in High Dimensions.Multiplicative attention essentially calculates a weighted dot product. As vector dimensions grow, the dot products can grow extremely large in magnitude, pushing the subsequent Softmax function into regions where gradients are extremely small (vanishing gradients). Additive attention uses a tanh non-linearity and a separate weight vector $v$, which helps stabilize the scoring magnitude and allows it to model complex, non-linear relationships between states more effectively without scaling.
+ Disadvantage: Additive attention is computationally more expensive and slower to train and infer.
